   IMPLEMENTADO: ✅
   SCRIPT:       block-ip-nginx.sh
   MÉTODO:       deny <IP>; en blocked_ips.conf
   RECARGA:      docker exec juice-proxy nginx -s reload
   
   Uso:
   $ ./src/scripts/block-ip-nginx.sh block 192.168.1.100
   $ ./src/scripts/block-ip-nginx.sh unblock 192.168.1.100
   $ ./src/scripts/block-ip-nginx.sh list
   
   Características:
   • Bloqueo sin downtime (recarga en caliente)
   • Validación de sintaxis antes de aplicar
   • Backup automático de configuración
   • Logging de todas las acciones
   • Soporte para múltiples IPs

✅ 2. BLOQUEO TEMPORAL (iptables/pfctl)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   IMPLEMENTADO: ✅
   SCRIPT:       block-ip-iptables.sh
   MÉTODO:       iptables -A INPUT -s <IP> -j DROP (Linux)
                 pfctl (macOS - documentado)
   
   Uso:
   $ sudo ./src/scripts/block-ip-iptables.sh block 192.168.1.100
   $ sudo ./src/scripts/block-ip-iptables.sh block 192.168.1.100 3600  # 1 hora
   $ sudo ./src/scripts/block-ip-iptables.sh unblock 192.168.1.100
   $ sudo ./src/scripts/block-ip-iptables.sh list
   
   Características:
   • Bloqueo a nivel kernel (más bajo nivel)
   • Soporte para bloqueo temporal con timeout automático
   • Bloqueo de puertos específicos
   • Listado de reglas activas
   • Flush de todas las reglas con confirmación

ESCENARIO: Detección de Ataque SQL Injection
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 🔍 DETECCIÓN (Automática)
   └─► Kibana detecta patrón: message:*"OR 1=1"*
   └─► Tiempo de detección: < 1 minuto

2. 🔔 ALERTA (Automática)
   └─► Notificación a Slack: "🚨 SQL Injection detectado"
   └─► Email a security-team@empresa.com
   └─► Tiempo de notificación: < 30 segundos

3. 📊 ANÁLISIS (Manual - 1-2 minutos)
   └─► Blue Team revisa logs en Kibana
   └─► Query: message:"OR 1=1" AND @timestamp > now-5m
   └─► Identifica IP atacante: 192.168.1.100

4. 🛡️ BLOQUEO INMEDIATO (Manual - 30 segundos)
   └─► Nivel 1 - Nginx:
       $ ./src/scripts/block-ip-nginx.sh block 192.168.1.100
   └─► Nivel 2 - Sistema (opcional):
       $ sudo ./src/scripts/block-ip-iptables.sh block 192.168.1.100

5. 🔬 INVESTIGACIÓN PROFUNDA (5 minutos)
   └─► Activar debug logging:
       $ ./src/scripts/toggle-debug-logging.sh enable
   └─► Capturar payloads completos
   └─► Analizar en: /var/log/nginx/juice_debug.log

6. 📝 DOCUMENTACIÓN (Continuo)
   └─► Exportar evidencia desde Kibana
   └─► Screenshots de alertas
   └─► Timeline del ataque
   └─► Crear incident report

7. ✅ LIMPIEZA (Cuando sea seguro)
   └─► Desactivar debug logging:
       $ ./src/scripts/toggle-debug-logging.sh disable
   └─► Opcional - Desbloquear si falso positivo:
       $ ./src/scripts/block-ip-nginx.sh unblock 192.168.1.100

TIEMPO TOTAL DE RESPUESTA: < 10 minutos
